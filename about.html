Acerca de esta ediciónAbout this edition

Este archivo reúne 374 obras, publicadas como versión 0.1.0 el 2026-11-26.This archive holds 374 plays, published as version 0.1.0 on 2026-11-26.

LecturaReading

Cada obra tiene una portada, una página por acto, el texto completo en una página y sus estadísticas; una obra con notas tiene una página que las reúne, cada una enlazada a la palabra que glosa. Los versos se numeran de cinco en cinco; cada verso tiene su propia dirección, de modo que se puede compartir un enlace a él.Every play has a title page, one page per act, the full text on one page, and its statistics; a play with notes has a page listing them, each linked to the word it glosses. Verse is numbered every fifth line; each line has its own address, so a link to it can be shared.

CitarCiting

Cada portada da una cita de la edición. Para citar un verso, enlácelo: al pulsar su número se copian su dirección y una cita.Each title page gives a citation for the edition. To cite a line, link to it: tapping a verse number copies its address and a citation.

FuentesSources

La fuente TEI-XML de cada obra se publica junto a sus páginas y se puede descargar desde su portada.Each play's TEI-XML source is published beside its pages and can be downloaded from its title page.

PrincipiosPrinciples

El archivo es HTML, CSS y JavaScript sencillos, sin servidor y sin nada cargado de fuera, según losThe archive is plain HTML, CSS and JavaScript with no server and nothing loaded from elsewhere, following the principios EndingsEndings principles. Funciona igual abierto desde un disco.It works the same opened from a disk.

Los enlaces de la banda al portal de EMOTHE (Portal, Base de datos) salen del archivo hacia el sitio al que pertenece y necesitan conexión; nada de lo que una página necesita para funcionar está fuera de él.The band's links to the EMOTHE portal (Portal, Database) lead out of the archive to the site it belongs to, and need a connection; nothing a page needs to work is outside it.

About this edition

This archive holds 372 plays, published as version 0.1.0 on 2026-10-08.

Reading

Every play has a title page, one page per act, the full text on one page, and its statistics. Verse is numbered every fifth line; each line has its own address, so a link to it can be shared.

Citing

Each title page gives a citation for the edition. To cite a line, link to it: tapping a verse number copies its address and a citation.

Sources

Each play's TEI-XML source is published beside its pages and can be downloaded from its title page.

Principles

The archive is plain HTML, CSS and JavaScript with no server and nothing loaded from elsewhere, following the Endings principles. It works the same opened from a disk.
